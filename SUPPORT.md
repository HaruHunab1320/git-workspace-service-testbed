# Support

## Getting Help

If you need help with this project, please open a GitHub Issue on this repository.

When opening an issue, include:

- A clear and descriptive title
- Steps to reproduce the problem (if applicable)
- Expected vs. actual behavior
- Relevant logs, screenshots, or error messages
- Your environment details (OS, runtime version, etc.)

## Security Issues

If you discover a security vulnerability, please open a GitHub Issue with the label `security`.

## Feature Requests

To request a new feature, open a new issue and select the **Feature Request** template.
