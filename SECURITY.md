# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public issue.** Instead, send an email to the maintainers with the following details:

- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 72 hours and aim to provide a resolution timeline within one week.

## Supported Versions

Security updates are applied to the latest version on the `main` branch.

## Scope

This policy applies to the cozy-village codebase hosted in this repository. Third-party dependencies are outside the direct scope of this policy, but we will coordinate with upstream maintainers when applicable.
